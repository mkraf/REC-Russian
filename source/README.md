# Исходники установщика

Здесь лежит исходный код установщика (`installer`) и деинсталлятора (`uninstaller`). Оба написаны на Go без сторонних библиотек: окна рисуются напрямую через Win32 API.

## Что делает установщик

1. Распаковывает вшитые файлы во временную папку.
2. Сохраняет `REC.pck` как `REC.pck.original`, если копии ещё нет.
3. Запускает `xdelta3.exe`, который накладывает патч `ru_patch.xd3` на оригинальный `REC.pck`.
4. Подменяет `data_REC_windows_x86_64\REC.dll` на изменённый `REC_ru.dll` (оригинал сохраняется как `REC.dll.original`).
5. Копирует `REC_Russian_Uninstall.exe` в папку игры и добавляет запись «REC — Русификация» в список установленных программ (`HKCU\...\Uninstall`).

Сетевых вызовов нет, права администратора не нужны.

## Что делает деинсталлятор

Возвращает `REC.pck` и `REC.dll` из `.original`, удаляет запись в реестре и сам себя.

## Как собрать

Нужен Go 1.24+. Установщик ожидает папку `files/` рядом с `main.go` с четырьмя файлами: `ru_patch.xd3`, `REC_ru.dll`, `xdelta3.exe` и собранный `REC_Russian_Uninstall.exe`. Сами эти файлы в репозитории не лежат, потому что содержат данные игры.

    cd uninstaller
    set GOOS=windows
    go build -ldflags "-H windowsgui" -o REC_Russian_Uninstall.exe .

    cd ../installer
    go build -ldflags "-H windowsgui" -o REC_Russian_Setup.exe .

Иконка и манифест подключаются отдельным файлом ресурсов (`.syso`) и в исходники не входят. Без него программа собирается и работает, только без иконки.
