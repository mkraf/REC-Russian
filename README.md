# REC — русификатор

Неофициальный перевод игры [REC](https://moondev64.itch.io/rec) на русский язык. Версия игры: v0.5.2.0.2, Windows.

Перевод не идеальный: местами бывают баги, обрезанный или непереведённый текст. Если нашли такое, напишите в [Issues](../../issues), лучше со скриншотом.

## Как установить

Скачайте `REC_Russian_Setup.exe` из [Releases](../../releases), закройте игру, запустите установщик и укажите папку, где лежат `REC.exe` и `REC.pck`. Нужна оригинальная игра: в установщике только патч.

Windows может ругнуться (SmartScreen), потому что у файла нет платной подписи. Нажмите «Подробнее», потом «Выполнить в любом случае».

## Как удалить

Через «Приложения» в Windows (пункт «REC — Русификация») или файлом `REC_Russian_Uninstall.exe` в папке с игрой. Оригинальные файлы вернутся сами.

## Что не переведено

Сокращения дней недели (TUE и т.п.), «рр» и пара мелочей вроде AUTO-SKIP: игра берёт их прямо из кода.

## Обновления игры

Патч сделан под v0.5.2.0.2. После обновления игры установщик может не подойти. Тогда он просто напишет об ошибке и ничего не сломает, а русификатор придётся подождать.

## Права

Игра принадлежит moondev64, это фанатский перевод, не связанный с автором. Файлов игры в репозитории нет.
