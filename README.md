REC — Русификатор / Russian translation
Неофициальный перевод игры REC (itch.io) на русский язык.
Unofficial Russian translation for the game REC by moondev64.
Версия игры / Game version: v0.5.2.0.2 (Windows)
Что переведено / What is translated
главное меню, настройки, загрузка/сохранение
магазин (предметы, улучшения, описания, требования)
PEEP: страницы, камера и улучшения, почта, магазин
статистика и отношения
письма, включая запросы на стрим (сгенерированные игрой тоже)
Не переведено: сокращения дней недели (TUE и т.п.) и единица «рр» — игра использует их в коде.
Not translated: weekday abbreviations (TUE, etc.) and the "pp" currency unit (used in game code).
Установка / Installation
Скачайте `REC_Russian_Setup.exe` со страницы Releases.
Закройте игру и запустите установщик.
Выберите папку с игрой (где лежат `REC.exe` и `REC.pck`) и нажмите «Установить».
Запускайте `REC.exe` как обычно.
Нужна купленная/скачанная оригинальная игра. Установщик содержит только патч, а не саму игру.
> **Windows SmartScreen** может показать предупреждение, потому что файл не имеет цифровой подписи.
> Нажмите «Подробнее» → «Выполнить в любом случае». Проверка на вирусы: _(ссылка VirusTotal)_.
Удаление / Uninstall
Установщик создаёт резервные копии оригинала в папке игры:
`REC.pck.original` → верните как `REC.pck`
`data_REC_windows_x86_64\REC.dll.original` → верните как `REC.dll`
Обновления игры / Game updates
Перевод рассчитан на версию v0.5.2.0.2. После обновления игры установщик может не подойти — тогда он сообщит об ошибке и ничего не изменит. Дождитесь новой версии русификатора или откройте issue.
Проблемы / Issues
Нашли непереведённый или обрезанный текст? Откройте issue и приложите скриншот и версию игры.
