## Что переведено

- главное меню, настройки, загрузка и сохранение
- магазин: предметы, улучшения, описания и требования
- PEEP: страницы, камера и улучшения, почта, магазин
- статистика и отношения
- письма, включая запросы на стрим

**Не переведено:** сокращения дней недели (TUE и т.п.) и единица «рр» — игра использует их в коде.

## Установка

1. Скачайте `REC_Russian_Setup.exe` в разделе [Releases](../../releases).
2. Закройте игру и запустите установщик.
3. Выберите папку с игрой (где лежат `REC.exe` и `REC.pck`) и нажмите «Установить».
4. Запускайте `REC.exe` как обычно.

Нужна оригинальная игра. Установщик содержит только патч, а не саму игру.

> **Windows SmartScreen** может показать предупреждение, потому что файл не имеет цифровой подписи.
> Нажмите «Подробнее» → «Выполнить в любом случае».

## Проверка на вирусы

Установщик проверен на **[VirusTotal](https://www.virustotal.com/gui/file/19460dde9102b753be197f9f519554e6e158ef7d6c4c8ea3a7846738af19c730)**: **8 из 71** антивирусов показали срабатывание, остальные 63 ничего не нашли.

Это **ложные срабатывания**. Все восемь называют не конкретный вирус, а общую эвристику («подозрительный файл», «машинное обучение», «generic»):

| Антивирус | Что показал |
|---|---|
| Microsoft Defender | `Trojan:Win32/Wacatac.B!ml` |
| Google | `Detected` |
| CrowdStrike Falcon | `Win/malicious_confidence_70%` |
| Elastic | `Malicious (high confidence)` |
| SentinelOne | `Static AI - Suspicious PE` |
| Bkav Pro | `W32.Malware.E2D6E32F` |
| Ikarus | `Trojan-Dropper.WinGo.Agent` |
| MaxSecure | `Trojan.Malware.300983.susgen` |

### Почему так происходит

Установщик написан на языке Go и не подписан цифровой подписью (она стоит денег). Для антивирусов с машинным обучением это уже повод для подозрения. К тому же он делает вещи, которые обычно делают и вредоносные программы:

- **Внутри лежат другие файлы.** Патч (около 28 МБ), изменённый `REC.dll`, утилита `xdelta3.exe` и деинсталлятор вшиты в один exe. Из-за этого `Ikarus` относит его к «dropper» (программа, которая распаковывает другие файлы).
- **Запускает сторонний `xdelta3.exe`.** Это открытая утилита, которая накладывает патч на `REC.pck`.
- **Меняет файлы другой программы.** Он подменяет `REC.pck` и `REC.dll` в папке игры, предварительно сохранив оригиналы как `.original`.
- **Пишет в реестр.** Создаёт запись «REC — Русификация» в списке установленных программ, чтобы можно было удалить через «Параметры → Приложения».
- **Деинсталлятор удаляет сам себя.** Он делает это через временный скрипт `cmd`, а это известный приём у вредоносов.

### Чего установщик не делает

- не подключается к интернету;
- не просит права администратора;
- не запускается вместе с Windows и не остаётся в памяти;
- не трогает ничего, кроме папки игры, временных файлов и одной записи об удалении в реестре.

### Если Windows блокирует файл

Откройте «Защита от вирусов и угроз → Журнал защиты», найдите `REC_Russian_Setup.exe` и выберите «Разрешить на устройстве». Затем запустите установщик снова.

Хэш файла (SHA-256), чтобы вы могли сверить скачанное с проверенным:

`19460dde9102b753be197f9f519554e6e158ef7d6c4c8ea3a7846738af19c730`

## Удаление

Вместе с русификатором в папку с игрой ставится деинсталлятор `REC_Russian_Uninstall.exe`. Запустите его и нажмите «Да»: оригинальные файлы игры вернутся, а сам деинсталлятор удалится.

Также удалить можно через «Параметры → Приложения → REC — Русификация».

## Обновления игры

Перевод рассчитан на версию **v0.5.5.2**. После обновления игры установщик может не подойти: тогда он сообщит об ошибке и ничего не изменит. Дождитесь новой версии русификатора.

Игра принадлежит её автору, **moondev64**. Это неофициальный фанатский перевод, не связанный с автором. Файлы игры в репозитории не распространяются.
